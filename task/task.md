# Проект: Sori

## 1. Формулировка задачи

Цель проекта - создать веб-приложение Sori, где персонаж 
танцует под музыку которую загружает пользователь

Задача: пользователь заходит на сайт, загружает mp3 трек, 
слушает его прямо в браузере и наблюдает как персонаж Sori 
двигается в ритм баса. Интерфейс выполнен в стиле музыкальной платформы - 
минималистичный, ночной и дневной режим по кнопке + Spatial UI

## 2. Аудитория

Люди которые слушают музыку и хотят визуального сопровождения
Возраст 12 - 30 лет, интересуются музыкой, эстетикой, дизайном

## 3. Трафик

Проект учебный. Ожидаемая аудитория - студенты и знакомые, 
100–300 уникальных посетителей

## 4. Что предлагаю

Бесплатный сервис с уникальным персонажем Sori который 
реагирует на музыку пользователя в реальном времени
Аналогов с персонажем в стиле музыкальных платформ нет

## 5. Как реализую

Приложение на Vue 3. Анализ громкости баса через Web Audio API 
браузера - персонаж прыгает когда бас громкий. Ночной и дневной
режим переключается одной кнопкой. Загрузка mp3 с устройства
