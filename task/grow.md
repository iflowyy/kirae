# Развитие и улучшения — kirae

## Обсуждение для развития проекта

### Краткосрочные улучшения ( 1–2 месяца )

- Добавить реальные видеоролики в карусель вместо заглушек
- Настроить контактную форму с отправкой на email ( через Formspree или EmailJS )
- Добавить страницу отдельного проекта с детальным описанием кейса
- Подключить Google Analytics для отслеживания поведения посетителей

### Среднесрочные улучшения ( 3–6 месяцев )

- Добавить раздел "Обо мне" с историей автора и инструментами
- Реализовать фильтрацию проектов по типу ( монтаж / анимация / moodboard )
- Добавить раздел отзывов от заказчиков
- Оптимизировать под поисковые системы : meta-теги , sitemap , robots.txt

### Долгосрочные улучшения ( 6+ месяцев )

- Перевести сайт на полноценный многостраничный SPA с роутингом Vue Router
- Добавить страницы отдельных проектов с видео и описанием процесса
- Добавить блог / заметки о процессе работы
- Реализовать мультиязычность ( русский / английский ) для работы с зарубежными заказчиками
- Рассмотреть переход на SSR ( Nuxt.js ) для улучшения SEO

### Монетизация и продвижение

- Публиковать превью работ в Instagram с ссылкой на сайт
- Разместить ссылку на сайт в Telegram-профиле и каналах
- Участвовать в профессиональных сообществах монтажёров
