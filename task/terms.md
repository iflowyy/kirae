Техническое задание — kirae
1. Введение
Данное техническое задание описывает требования к разработке сайта-портфолио для визуального автора и монтажёра .

Цель проекта — создать сайт с чистым , минималистичным интерфейсом , где потенциальный заказчик может посмотреть работы и выйти на контакт .

Проект должен обеспечивать стабильную работу как при обычной нагрузке , так и при увеличении количества пользователей .

2. Общие сведения
2.1 Назначение системы
Сайт kirae предназначен для презентации услуг визуального автора :

монтаж видео
визуальные концепции и moodboard
цветокоррекция
анимация
2.2 Основные конкурентные преимущества проекта
Чистый визуал — минимализм без перегруза , всё внимание на работах
Быстрая загрузка — оптимизированная вёрстка без лишних зависимостей
Карусель проектов — удобный просмотр работ с поддержкой видео mp4
Адаптивность — корректная работа на всех устройствах
FAQ — снимает типовые вопросы заказчика до момента контакта
2.3 Целевая аудитория
Бренды , агентства и частные заказчики , 20–40 лет . Принимают решение визуально . Смотрят с телефона и компьютера .

3. Структура сайта
На всех страницах в верхней части расположены :

Логотип / имя автора ( ссылка на главную )
Навигация : Посмотреть проекты / Контакт
Кнопка-CTA в навбаре
В нижней части :

Хлебная крошка
4 колонки ссылок : Проекты / Контакт / Подход / Прочее
Строка копирайта
Страница /
Hero-блок : заголовок + описание + кнопки
Градиентный блок : акцент на подходе автора
Карусель проектов с 5 слайдами
Блок подхода : 4 карточки ( Монтаж / Цвет / Moodboard / Анимация )
FAQ : 6 вопросов с раскрывающимися ответами
Футер
4. Описание экранов

FAQ

Футер

5. Требования к дизайну
Стиль: минималистичный , тёмная тема , премиальный

Фон: #000000

Основной текст: #f5f5f7

Вторичный текст: #86868b

Акцент: #2997ff

Кнопка: #0066cc

Шрифт: SF Pro Display / system-ui / Helvetica Neue

Анимации: только мягкие — fade-in , плавный скролл , hover-эффекты

Примеры сайтов похожего стиля :

https://linear.app — минимализм , тёмная тема
https://vercel.com — чистота , воздух
6. Технические требования
Фреймворк: Vue 3 + Vite
Адаптив: мобильные ( 360px+ ) , планшет ( 768px+ ) , десктоп ( 1280px+ )
Браузеры: Chrome 90+ , Safari 14+ , Edge 90+
Без лишних зависимостей — чистая структура компонентов
Запуск: npm install → npm run dev
Разрешения экранов
Десктоп : 1280×768 — 1920×1080
Планшет : 768×1024
Мобильные : 360×480 и выше
