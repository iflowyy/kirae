# Техническое задание — sori

## 1. Назначение

Сайт-портфолио визуального автора. Цель — первое впечатление, показ работ, выход на контакт.

## 2. Целевая аудитория

Бренды и частные заказчики, 20–40 лет. Принимают решение визуально. Смотрят с телефона и компьютера.

## 3. Структура

На всех страницах:
- Логотип sori (ссылка на главную)
- Навигация: Проекты / Контакт
- Кнопка-CTA в навбаре

Страницы:
- `/` — главная (hero → радуга → карусель проектов → подход → FAQ → футер)

## 4. Описание блоков

### Hero
- Превью-мокап вверху
- Крупный заголовок + описание + две кнопки

### Радужный блок
- Полноширинный цветной градиент (как Apple Logic Pro)
- Блок с текстом: лейбл + заголовок + описание с акцентами

### Карусель (Проекты)
- 5 слайдов, активный — по центру, соседние притушены
- Apple-style управление: dots-pill + круглая кнопка play/pause
- Прогресс-бар внутри активного слайда
- Поддержка mp4-видео (положить в `/public/videos/`)

### Подход (Features)
- Горизонтальный скролл карточек со стрелками
- 4 карточки

### FAQ
- Аккордеон + сноски

### Футер
- Хлебная крошка + 4 колонки + копирайт

## 5. Требования к дизайну

- Фон: `#000000`
- Текст: `#f5f5f7`
- Серый: `#6e6e73`
- Акцент: `#2997ff`
- Кнопка: `#0066cc`
- Шрифт: SF Pro Display / system-ui
- Анимации: только мягкие

## 6. Технические требования

- Фреймворк: **Vue 3 + Vite**
- Адаптив: 360px+, 768px+, 1280px+
- Браузеры: Chrome 90+, Safari 14+, Edge 90+
- Запуск: `npm install` → `npm run dev`
