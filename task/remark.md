# Обсуждение — kirae

## Замечания по проекту

### Что работает хорошо

- Визуальная концепция читается чётко с первого экрана
- Карусель с прогресс-баром и кнопкой play/pause работает стабильно
- FAQ снимает типовые вопросы без лишней переписки
- Адаптивность на мобильных устройствах реализована корректно
- Градиентный блок создаёт ощущение творческого проекта

### Что можно улучшить

- **Реальные работы** — сейчас в карусели заглушки . После добавления своих видео сайт заработает в полную силу
- **Контактная форма** — сейчас кнопка ведёт к футеру . В следующей версии можно добавить реальную форму с отправкой на email
- **Анимации по скроллу** — reveal-анимации подключены , но можно добавить больше точек появления
- **SEO** — добавить meta-теги description и og:image для корректного отображения при репосте ссылки

### Технические замечания

- Проект работает корректно в Chrome , Safari , Edge
- На очень маленьких экранах ( менее 360px ) карточки Features сжимаются — стоит добавить минимальную ширину
