# kirae — visual author

Сайт-портфолио визуального автора и монтажёра .

## Установка
```bash
npm i
```

## Запуск
```bash
npm run dev
```

Открой в браузере : http://localhost:5173

## Сборка для продакшена
```bash
npm run build
```
