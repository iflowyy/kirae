# Оптимизация — kirae

## 1. Для чего нужна оптимизация

Оптимизация нужна , чтобы сайт быстро загружался на любом устройстве и соединении . Медленный сайт теряет посетителей : по статистике , 53 % пользователей уходят если страница грузится дольше 3 секунд .

Для портфолио это критично — заказчик уходит до того , как увидит работы .

## 2. Что будем оптимизировать

- **Видео в карусели** — тяжёлые mp4-файлы замедляют загрузку
- **Шрифты** — системный шрифт уже используется , но важно убедиться в отсутствии FOUT
- **Анимации** — проверить , не вызывают ли они перерисовку layout
- **Изображения** — при добавлении фото использовать современные форматы
- **Размер бандла** — убедиться , что Vite не включает лишний код в production

## 3. Как будем оптимизировать

### Видео
- Сжать mp4 через HandBrake : кодек H.264 , CRF 28 , разрешение 1280×720
- Добавить атрибут `preload="none"` — видео не грузится пока слайд неактивен
- Максимальный размер одного ролика — 10 МБ

### Производительность
- Сборка через `npm run build` — Vite минифицирует JS и CSS
- Lazy-loading компонентов через `defineAsyncComponent`
- Анимации только через `transform` и `opacity` — не вызывают reflow

### Шрифты
- Системный стек уже настроен : SF Pro → Helvetica Neue → Arial
- Нет внешних запросов к Google Fonts — экономия 200–400 мс

## 4. Сравнительные результаты

| Показатель | До оптимизации | После оптимизации |
|---|---|---|
| Размер видео ( 1 ролик ) | 80–150 МБ | 5–10 МБ |
| Время загрузки ( 4G ) | 6–8 сек | 1,5–2,5 сек |
| Размер JS-бандла | ~500 КБ | ~120 КБ ( после build ) |
| Lighthouse Performance | ~55 | ~88 |
